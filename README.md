* FCA_original.py has the code for K-clique Communities Detection in Social
Networks based on Formal Concept Analysis. The implementation matches with the paper.

* FCA.py is a modeified version of FCA_original.py for using it in FairCliqueMiner.
fc_miner.py holds the fair clique mining functions.

* The execution starts from experiment1.py
* experiment1.py prints tables 2,3,4,5 as given in the paper for the facebook dataset.
* First it calls load_facebook100_data() function that returns the output in format for different combination of attributes based on the number of nodes given as input.
* As given in AFCMiner paper we have used for 6 subset with 250,500,750,1000,1250,1500 nodes. This subset is mentioned in the experimemt_utils.py like SUBSET_SIZES = [250,500, 750,1000, 1250, 1500] we can edit this to add subsets or remove subsets.
* based on the way we want to sample the data we call the function load_facebook100_data() from preprocess_fb100.py or sparse_preprocess.py
* After preprocessing it gets the data and runs BKMiner from bk.py and FairCliqueMiner from fc_miner.py (This holds the implementation as given in the paper but its slower) or optimal.py (This has the optimal version of FCA generated by ai)
* fc_miner.py calls the ConceptBuilder from FCA.py to generate all the concpets.
